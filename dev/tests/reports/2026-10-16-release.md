## Bugs found and fixed

### FIX-001: the MFD came back with the next MFD (reported by the user)
- **Cause:** leaving cursor mode only hid the MFD; it stayed open and reappeared when the cursor came back.
- **Fix:** once the MFD has been seen with the cursor up, leaving cursor mode closes it (saved or not). It also closes if the cursor hasn't come up within 1 second of opening, so it can't stay open invisibly.
- **Status:** fixed in code; **needs in-game check** (TEST_PLAN 1–6).

### FIX-002: the MFD failed without psi_autocast
- **Found by:** writing TEST_PLAN test 21.
- **Cause:** the MFD called psi_autocast's `PsiSplitList`, `PsiIsDigits` and `PsiUnderscoresToSpaces`; without psi_autocast, opening a key with a saved macro raised an error and the guard closed the MFD.
- **Fix:** the MFD has its own copies; `test_mfd_defines_every_psi_function_it_calls` keeps it that way.
- **Status:** fixed; **needs in-game check** (TEST_PLAN 21).

### FIX-003: the setup scripts hung where Git's Unix tools are on the PATH
- **Found by:** the setup-script tests hanging.
- **Cause:** a bare `find` ran Git for Windows' Unix `find`, which searched the whole drive. Git's installer offers to put those tools on the system PATH, so players can hit it.
- **Fix:** the game-running and registry checks use `findstr` (no Unix namesake); the key count calls `%SystemRoot%\System32\find.exe`. Both scripts.
- **Status:** fixed and tested.
